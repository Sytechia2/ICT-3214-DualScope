DualScope: files kept on Google Drive
====================================

Some of DualScope's data and results are too large for the code repository.
They are kept in a shared Google Drive folder called "Security Analytics Data":

    https://drive.google.com/drive/folders/1uccDsuaxZahnTwdyiIGJIW2MzZ1dBQdq?usp=sharing

This file lists what is in that folder and where each file goes when you
unzip it. All paths are relative to the root of the repository (the folder
that holds README.md).

You do not need any of these files to install DualScope, run the tests, run
the sample pipeline or open the dashboard on the sample. The user manual
(docs/user_manual.md) says when each one is needed.

Final Model / outputs
---------------------

Unzip each of these into the outputs/ folder of the repository. Each zip
already contains its own top-level folder, so outputs/handoff.zip becomes
outputs/handoff/..., and so on.

handoff.zip (about 2 MB)
    The final model's alerts for test days 17 to 30: 497 incidents, the
    alerted hours and every login event they cite.
    Unzips to: outputs/handoff/final_test_alerts_v1/
    Needed for: opening the dashboard on the real results (manual section 6).

investigations.zip (about 8 MB)
    The Gemini summaries for those 497 incidents in all three views (AI only,
    AI with ATT&CK, and AI with ATT&CK after the evidence check), with the
    prompts and the run log. It also holds a 3-incident trial run (smoke) and
    an earlier run that was stopped because some replies were cut off
    (aborted_maxtokens_8192). The dashboard uses gemini_v1 only.
    Unzips to: outputs/investigations/gemini_v1/ (plus the two older runs)
    Needed for: the Investigation tab in the dashboard (manual section 6).

final_test.zip (about 186 MB)
    The scores and results of the one-time final test on days 17 to 30.
    These days must never be scored again, so this is the only copy of the
    test scores.
    Unzips to: outputs/final_test/
    Needed for: rebuilding the alert package (docs/investigation/alert_handoff.md)
    and checking the test results.

evaluation.zip (about 0.1 MB)
    Evaluation results: the model comparison on days 13 to 16, the timing
    and error analysis, and the review of the AI summaries (the 25-incident
    sample, the reviewers' labels and the scores).
    Unzips to: outputs/evaluation/
    Needed for: checking the numbers in docs/evaluation/ and
    docs/investigation/investigation_review.md.


Final Model / models
--------------------

fusion.zip (about 0.1 MB)
    The frozen fusion models from model development and from the final test,
    each with its manifest.
    Unzips to: models/fusion/
    Note: the copy the pipeline uses is already in the repository under
    models/release/, so this is only needed to retrace the original runs.


Long Term Graphs
----------------

Results of the graph detector, which was studied but is not part of the
final model.
    - Eight result charts (01_metric_summary.png to 08_relationship_example.png).
    - graph_scores_v1.zip (about 280 MB): the graph detector's scores.
      Unzips to: outputs/graph_scores_v1/
See docs/detectors/graph_detector.md and docs/detectors/graph_model_evaluation.md.


Short Term Seq Detector
-----------------------

seq-gru-ae-v1-L32-h32-91e4b11d34.zip (about 2 GB)
    The first frozen GRU sequence detector and its scores for every
    user-hour of days 1 to 30, split into train, validation and test zips,
    with a README.txt and SHA256SUMS.txt.
    See docs/detectors/sequence_detector_handoff.md for where each part goes.


Processed LANL data
-------------------

Open the .7z files with 7-Zip. They save the hours it takes to rebuild them from the
raw LANL files. Unzip into data/processed/.

lanl_auth_days_01_30.7z
    The LANL login events and red-team labels for days 1 to 30, converted
    to Parquet.
    Unzips to: data/processed/lanl_auth_days_01_30/
    See docs/data/lanl_ingestion.md.

lanl_features_days_01_30.zip
    The first feature build, used in the earlier sequence and graph
    detector work.
    Unzips to: data/processed/lanl_features_days_01_30/

lanl_features_v2_days_01_30.7z (about 15 GB; about 23 GB unzipped)
    The feature build the final model uses.
    Unzips to: data/processed/lanl_features_v2_days_01_30/
    See docs/data/lanl_features.md and docs/evaluation/experiment_features_v2.md.

With lanl_auth_days_01_30 and lanl_features_v2_days_01_30 in place, the full
pipeline (python scripts/run_pipeline.py --profile full) reuses them instead
of rebuilding from the raw files (manual section 9).


The raw data
------------

The raw LANL files are not on the Drive. Download auth.txt.gz and
redteam.txt.gz from https://csr.lanl.gov/data/cyber1/ (manual section 9).
